# AGD Language Support 
 AGD Language Support provides syntax highlighting for the AGD programming language.
## Features -
  Highlights keywords like using:, let:,  if:, for:, while: -
  Supports data types: int, string, float, etc. -
  Highlights numbers and strings - Custom .agd file support
## Usage 
  1. Create a file with .agd extension 
  2. Open it in VS Code 
  3. Syntax highlighting will automatically apply
## Example 
   using: ioput;
   let: int x = 10; 
   if: x > 5 { 
    op: "Hello World";
         }
